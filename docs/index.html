CPU — its own physics

\[T_{CPU}=\frac{InstructionCount\times CPI}{ClockRate}\qquad AMAT=HitTime+MissRate\times MissPenalty\]
\[S_{total}=\frac1{(1-P)+P/S}\]

LeeWay does not apply GPU residency physics to CPU execution. The CPU adapter observes utility, frequency, privileged work, paging, queue pressure and context switching, then produces a 16×6 Formula history.

Measured: 6 threads was the strongest efficiency mode; 8 threads the lowest-latency point; 10 threads a strong throughput point. Higher thread counts increased scheduling/memory-system overhead.

Failure retained: 16-thread policy reached unacceptable duration/timeout.

GPU / VRAM — performance and capacity ladder

\[VRAM_t=W(A_t)+KV_t+Compute_t\]

Measured ladder: 1× → 2.37× → 2.59× → 3.43× → 5.35× → 7.46× → 11.18× VRAM working-set reduction.

\[16\times\Rightarrow199{,}473{,}889\ bytes\quad 32\times\Rightarrow99{,}736{,}945\quad 64\times\Rightarrow49{,}868{,}472\]

Current blocker: one measured GPU layer alone required about 243.44 MiB of CUDA model buffer before compute overhead, so whole-layer residency cannot reach the 16× budget.

Next: layer → tensor → block → active working set.

PCIe / Interconnect

\[BW\approx Lanes\times TransferRate\times EncodingEfficiency\]

Software cannot create physical lanes. LeeWay targets avoidable copies, synchronization, queueing and poor locality so useful work per physical byte can increase.

Status: telemetry exists, but a dedicated isolated PCIe A/B superiority campaign is still an open proof gate.

USB / Device I/O

\[BytesToTransfer\approx MissingVerifiedState\]

The Fold6 campaign proved USB/ADB device authority, read/write access, phone-side SHA equality and native Android ARM64 runtime execution. No claim is made that Formula increases USB electrical signaling rate.

Storage / Media

\[SAF=\frac{P_{new}}{L(O)}\qquad SAFA=\frac1{SAF}\qquad SHA256(O')=SHA256(O)\]

Exact representation and behavioral representation are separated. On real Fold6 media, generic exact compression often had little room; media-domain strategies produced much larger reductions.

Images: tested JPEG XL reductions about 44–74% depending content/quality. Speech: selected Opus 24 kb/s repeatedly reduced tested recordings about 82–89%. Video: strong HEVC/AV1 reductions were measured, but a fixed aggressive policy was rejected because fidelity varied by clip.

Rejected: raw decoded-RGB temporal delta made the tested JPEG burst roughly 4.5× larger despite exact decoded-pixel reconstruction.

Models / Runtime

\[StoredArtifact\ne RuntimeWorkingSet\ne EffectiveExecutionBurden\]

A real quantized GGUF only improved from about 2.130% to 2.135% under the tested exact compression path. Exact reconstruction passed; the large compression claim failed. That result redirected research toward model-state representation and bounded working sets.

Current GPU capacity evidence: 11.18× VRAM working-set reduction. Not yet proven: 16× total representation or 27B Gemma live Fold6 conversation.

# Decision Ledger

## D-001 — Non-LLM cognition kernel
Status: APPROVED
Decision:
Persistent cognition must exist without an LLM. LLMs are optional interface/language providers.
Reason:
Creator requirement and architectural independence.

## D-002 — Belief as revisable probability
Status: APPROVED / CREATOR CORRECTION
Decision:
Belief is a probability distribution that may be stable but is never treated as permanently true.

## D-003 — Preserve canonical Formula
Status: APPROVED
Decision:
Do not modify LEEWAY-FORMULA-v1.0 for machine consciousness.
Route measured cognition through a domain adapter and runtime-state-v1.

## D-004 — Structured awareness state, not one magic score
Status: APPROVED
Decision:
Operational awareness remains a structured state. Single awareness-number proposals are rejected until/unless a specific bounded diagnostic is justified.

## D-005 — Initial six Formula bridge dimensions
Status: PROPOSED / CANDIDATE
Dimensions:
belief entropy;
precision-weighted prediction error;
free-energy-rate valence;
information gain;
selected-policy expected free energy;
global-access ratio.
Promotion requires calibration and ablation evidence.

## D-006 — Dream provenance
Status: APPROVED
Decision:
Dream/replay evidence is permanently SIMULATED/OFFLINE and can never silently become external historical fact.

## D-007 — Global access is operational, not phenomenal proof
Status: APPROVED
Decision:
Workspace acknowledgement ratio is an engineering proxy only.

## D-008 — Self-model contains inspectable facts
Status: APPROVED
Decision:
Self-model may not invent capabilities, authority, health or causal ownership.

## D-009 — Determinism first
Status: APPROVED
Decision:
First simulator is deterministic under fixed seed/config so every cognition cycle can be replayed and audited.

## D-010 — Small world before large world
Status: APPROVED
Decision:
Start with a hand-checkable partially observable finite-state world before complex robotics, language or open-web environments.

## D-011 — No Formula calibration by intuition
Status: APPROVED
Decision:
Ranges come from measured trace campaigns and holdout validation.

## D-012 — Consciousness claim boundary
Status: APPROVED
Decision:
No runtime state, Formula output, maturity level or benchmark alone establishes subjective experience or sentience.

## D-013 — Source code self-modification
Status: DEFERRED
Decision:
Initial learning modifies parameters/data only. Self-modifying source code requires a later separate governance design.

## D-014 — IIT
Status: RESEARCH COMPARATOR
Decision:
IIT may be studied or benchmarked, but it is not the current control kernel.

## D-015 — Initial implementation language
Status: PROPOSED
Decision:
Use deterministic Node.js ES modules to align with the existing canonical Formula runtime unless a stronger implementation reason emerges before MC-1 coding.


## D-016 — Oracle feedback boundary
Status: APPROVED FOR MC-G2 TESTING ONLY
Decision:
auditWorldState may be used to qualify memory/learning mechanics only when the feedback class is explicitly ORACLE_SUPERVISED_TEST_ONLY.
It is forbidden as evidence for autonomous-learning claims and must not silently enter production cognition inputs.

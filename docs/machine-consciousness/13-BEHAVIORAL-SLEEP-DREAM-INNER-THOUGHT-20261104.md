# Machine Consciousness Behavioral Mathematics — original dream, rest, inner thought and flow

## 1. Creator's full intended analogy

A person can deliberately think about a decision and direct an action, while many familiar physical activities proceed with limited conscious attention. The Creator calls the latter condition **"in the zone."** The intended LeeWay equivalent is **one persistent cognitive system with two cooperating functional lanes**, not two autonomous identities and not evidence of phenomenal consciousness:

- **Inner cognitive lane:** perception, revisable belief, prediction, goal-directed deliberation, uncertain hypotheses, private inner narration, memory, and counterfactual dream/replay. An inner thought may have verbal expression but its authoritative representation is a typed state object.
- **Embodied action lane:** previously authorized, bounded learned skill procedures in Runtime Fabric through Agent Lee/Device Bridge. Familiar routines may execute with low deliberation overhead; an unexpected event, expired authority, changed capability or failed prediction returns control to deliberation and original Veritas gates.

No Device Bridge action occurs just because a mode equals FLOW. The physical machine, like a human body, still requires a powered host, actual executor, creator scope, resources and independently qualified execution. These are **engineering analogies**, not claims of literal human sleep, emotions or a second sentient self.

## 4. The private inner voice

**Thought (canonical internal candidate):** a structured QUESTION, PREDICTION, COUNTERFACTUAL or REPAIR_HYPOTHESIS tied to the original mission and exact observed-state hash. The optional verbal rendering is a presentation service, never another independent executive, never a verified factual claim and never a required token generator.

**Spoken Agent Lee:** may present relevant, authorized portions of that internal state in a stable constitutional style. Privacy, permission, relevance, interruption and truth controls stay in existing conversational/Voice Fabric services. Inner narration must not be automatically streamed as continuous audio, and a simulated dream must not appear as a remembered real conversation.

This separates **thinking in state** from **saying thoughts aloud**.

## 5. Sleep and dreams as a measured learning gate

## 6. Flow, autonomic routines and the two-lane bridge

- **Deliberative selection:** Machine Consciousness proposes a typed plan, existing Formula reviews eligible decision evidence, Runtime Fabric authenticates and gates action.
- **Procedural flow:** A pre-existing authorized workplane task/skill may perform bounded repeated operations while the cognitive lane monitors outcome telemetry, errors, authority changes and mission checkpoint.
- **Return to deliberation:** error, revoked authority, novel event, expired lease, missing capability, unexpected output or resource pressure interrupts/suspends the flow through the **existing Runtime Fabric**. Neither lane can grant itself permission. This proposal is not a new scheduler/event bus.

A single workplane mission ID and one Agent Lee identity remain authoritative across both lanes. State transition and trigger parameters must be calibrated rather than chosen because they "feel human."

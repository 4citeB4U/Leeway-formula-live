## 4. Stage L1 — live shadow cognition

Authority:
OBSERVE ONLY.

Insertion point:
real Agent Lee ingress before local-model response generation.

Flow:

user/request event
-> shadow observation packet
-> bounded hypothesis/belief state
-> prediction / expected outcome
-> mechanical valuation
-> candidate policy state
-> workspace/self-model state
-> deliberation recommendation
-> NO EFFECT on model response
-> actual model/tool response
-> result comparison
-> shadow receipt

The shadow layer may not:
- change text;
- delay execution beyond a hard diagnostic budget;
- call consequential tools;
- change memory;
- choose actions.

Acceptance:
- no user-visible regression;
- deterministic receipts;
- bounded overhead;
- shadow state can be replayed;
- no fabricated observations;
- live and shadow result correlation is measurable.

Rollback:
disable one feature flag; existing Agent Lee request path remains unchanged.

# LeeWay Formula Funnel — Context, Knowledge and LLM Decision Engineering

The Formula Funnel puts context and decision-making under mathematical/evidence governance before an LLM or agent acts. It is not permission for an LLM to invent Formula states.

## Behavioral layer

[
S_t\rightarrow A_t\rightarrow O_t\rightarrow V_t\rightarrow L_{t+1}\rightarrow S_{t+1}
]

It asks what state is repeating, what pressure is accelerating, which capability is eligible, what action is authorized, and whether execution passed evidence requirements.

## Knowledge / epistemic layer

Claims are classified as identity, engineering/statistical model, optimization objective, heuristic, project target, standard-bound rule, empirical hypothesis, candidate extension or canonical binding.

Mathematical validity, domain validity, empirical validity, runtime validity and canonical validity are independent.

## Funnel stages

1. Recover continuity: phase, approvals, rejections, blockers, hashes, receipts.
2. Build the context envelope: human, device/system, agent, intent, environment, platform, capability, authority, permission, state, history, risk, connectivity, evidence, recovery, adaptation.
3. Ask **What are we not discovering?**
4. Ask **What needs to be enhanced?**
5. Normalize only measurable/authorized state.
6. Stage Formula input.
7. Execute canonical Formula only when actual evaluator authority exists.
8. Route capability/action.
9. Execute in reality.
10. Measure outcome.
11. Run Veritas.
12. Preserve PASS and FAIL.
13. Promote only verified learning.
14. Repeat the mandatory probes at the next state.

## Why it can improve LLM answers

The Funnel can reduce stale context, duplicate assumptions, reopened decisions, unsupported claims, wrong capability selection and premature stopping. The model sees a smaller, higher-signal decision surface.

Candidate objective:

[
C^*=\arg\min_C |C|\quad subject\ to\quad Correctness,Authority,Provenance,Risk
]

This objective is **candidate context-engineering mathematics**, not the canonical Golden kernel.

## Hard evidence rule

If runtime did not execute:

[
FORMULA\ EVALUATION=NOT\ EXECUTED
]

If execution occurred but was not verified:

[
EXECUTED\ne VERIFIED
]

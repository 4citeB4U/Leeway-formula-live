# Failure & Repair Ledger

Failures are scientific evidence.

## Model representation

### Generic compression plateau
Real quantized GGUF reduction remained near 2.13%. Exact reconstruction passed; material breakthrough failed.

### Cross-layer XOR
Residual entropy increased. **Rejected.**

### Experimental 8×16 interpretation
A non-canonical adapter grouped real tensor blocks, but exact residual storage became ~4.17% larger. **Rejected.** The work returned to Golden Formula authority.

## CPU

### Multi-model contamination
Three CPU-resident models distorted early generation results. Repaired through exclusive/isolated execution.

### Fixed thread policy
8 threads was not universal. CPU-native physics showed efficiency/latency/throughput modes.

### High-thread failure
16-thread campaign reached unacceptable duration/timeout. Preserved.

## GPU

### Fake GPU configuration boundary
NVIDIA environment variables existed, but Docker DeviceRequests was null. Repaired in canonical Compose.

### Mislabelled CPU lane
After GPU enablement the CPU target offloaded into VRAM. Run rejected.

### Whole-layer 16× floor
One GPU layer required ~243.44 MiB model buffer before compute overhead, already above the 16× target. Next gate: sub-layer tensor residency.

## Phone / media

### Cache-only first pass
Recovered 3.260 GiB but did not address media. Repaired by a separate media campaign.

### Raw temporal RGB delta
Decoded reconstruction passed; storage became much larger. Rejected.

### Fixed HEVC CQ32
Large reductions, inconsistent fidelity across clips. Universal policy rejected.

## Runtime compatibility

Reconstruction-v3 used APIs not exposed in Windows PowerShell 5.1. The authority code was not rewritten; execution moved to PowerShell 7 and passed.

FAIL\to Investigate\to Diagnose\to Repair\to Retest\to Verify\to Evidence
]

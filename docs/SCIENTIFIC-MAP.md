## Scientific claim classes

- **CANONICAL LEEWAY** — frozen/authorized definition, equation, vector, hash or rule.
- **PROVEN LEEWAY** — measured/executed result with evidence.
- **CANDIDATE / PROPOSED** — LeeWay mathematics or architecture not yet promoted.
- **EXTERNAL MATHEMATICS / RESEARCH** — established mathematics used as foundation/reference, never relabeled as LeeWay invention.
- **HISTORICAL EVIDENCE** — recovered earlier experiment/source that preserves chronology.
- **OPEN GAP / BLOCKED** — unresolved mathematics, runtime, evidence or authority boundary.

## The separation law

The Formula is not an LLM and an LLM is not the Formula.

[
FormulaDecision \ne RuntimeExecution \ne VeritasAcceptance
]

The equations define state transforms, ranking, gates and policy independent of whichever model/agent/tool consumes them. A physical or digital substrate still evaluates the equations and performs the selected action. CPU/GPU is therefore execution substrate, not the source of the mathematical decision.

## Core operating chain

[
Evidence\rightarrow State\rightarrow Formula\rightarrow Policy\rightarrow Execution\rightarrow Measurement\rightarrow Veritas\rightarrow Receipt\rightarrow Learning
]

No later stage may rewrite an earlier authority merely because an experiment looked successful.
